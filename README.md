# FlaFan

App de torcedor com todos os jogos do Flamengo, em todas as modalidades, e onde assistir a cada um.
Funciona no navegador do celular e pode ser instalado na tela inicial.

Sem vínculo oficial com o clube. A marca do app é própria; os escudos dos times aparecem só para identificar as partidas.

O guia para manter o app está em [GUIA.md](GUIA.md).
